UPDATED V2
1. Extract ZIP.
2. In Command Prompt:
python -m venv .venv
.venv\Scripts\activate.bat
python -m pip install -r requirements.txt
3. Set your password:
set SUPERIOR_ADMIN_PASSWORD=your-private-password
4. Run: python app.py
5. Open Chrome: http://127.0.0.1:5000

Registrations are stored locally in trekking.db and appear in the admin dashboard.
